ÜRÜN EKOSİSTEMİ
BLAGG Studio dört ana ürün/modül etrafında kurgulanacak:

1. BLAGG Studio
Public marka ve hizmet yüzü.
Premium renovasyon, yapı, tasarım ve uygulama stüdyosu.

2. BLAGG Remote
Müşterinin özel bağlantı ile projesini uzaktan takip ettiği alan.
Navbar veya ilgili alanlarda “BLAGG Remote” üzerine gelindiğinde Türkçe açıklama göster:
“Şehir dışında olsanız bile projenizi fotoğraflar, ödeme planı ve belgelerle tek bağlantı üzerinden takip edin.”

Mobilde hover olmadığı için bilgi ikonuna basınca açıklama açılmalı.

3. BLAGG Field
Usta/saha ekibinin fotoğraf, not ve iş durumu gönderdiği sade saha ekranı.
Usta sadece kendi iş kalemi, fotoğraf yükleme, not ve durum bildirme alanlarını görmeli.
Usta müşteri ödemelerini, şirket kârını veya teklif toplamını görmemeli.

4. BLAGG Control
Şirketin operasyon paneli.
Başvurular, teklifler, projeler, müşteriler, ustalar, tedarikçiler, fotoğraf onayları, finans, belgeler ve ayarlar buradan yönetilecek.

Ek premium konsept:
BLAGG Signature
Seçilmiş projeler için premium çalışma modeli.
Tasarım, malzeme seçimi, uygulama kontrolü ve özel proje takibini bir araya getiren rafine BLAGG hizmet yaklaşımı.

FOTOĞRAF ONAY SİSTEMİ
Bu sistem zorunlu.

Akış:
Usta → Admin Onayı → Müşteri

Usta BLAGG Field ekranından fotoğraf yükler.
Fotoğraf doğrudan müşteriye gitmez.
Admin panelinde “Onay Bekliyor” durumuna düşer.
Admin inceler.
Admin açıklamayı düzenleyebilir.
Admin iş kalemine bağlayabilir.
Admin müşteriye göster/gizle seçebilir.
Admin onaylarsa müşteri BLAGG Remote ekranında görür.
Admin reddederse müşteri görmez.

Fotoğraf statüleri:
- pending_review
- approved
- rejected

Ek alan:
visible_to_customer: true/false

Müşteri ekranı:
Sadece approved ve visible_to_customer true fotoğrafları göster.

Usta ekranı:
Fotoğraf yükledikten sonra mesaj:
“Fotoğrafınız BLAGG Studio ekibi tarafından incelendikten sonra proje kaydına eklenecektir.”

TEKLİF SİSTEMİ
Başvurudan teklif oluşturma akışı hazırlanacak.

Akış:
1. Müşteri /teklif-al formunu doldurur.
2. Başvuru BLAGG Control paneline düşer.
3. Admin başvuruyu açar.
4. Admin başvuruyu PDF/print/download edebilir.
5. Admin “Teklife Dönüştür” butonuna basar.
6. Sabit BLAGG Studio teklif şablonu açılır.
7. Admin iş kalemlerini, fiyatları, hariçleri ve ödeme planını girer.
8. Teklif toplamı hesaplanır.
9. Teklif print/PDF uyumlu görünür.
10. Teklif onaylanırsa proje oluşturulabilir.

- draft
- sent
- approved
- rejected
- converted_to_project
