BUILD FUNCTIONAL MVP FLOW AND SIMPLIFY UX FOR REAL USERS.

IMPORTANT:
- UI language must remain Turkish.
- Brand: BLAAG Construction and Architecture.
- This is NOT SaaS.
- This is a construction, renovation and real estate service company.
- Do not add external backend.
- Do not add new dependencies unless absolutely necessary.
- Use localStorage/mock storage for now.
- Build must pass.
- Prioritize reliability over complexity.

MAIN USER TEST FINDINGS:
1. Site does not currently work correctly as a real flow.
2. Photos cannot be uploaded in a useful way.
3. Forms do not reach admin.
4. Important fields can be skipped or filled with fake numbers.
5. Site is too text-heavy, like a book.
6. 65+ users may struggle to understand what to do.
7. Mobile layout feels crowded and confusing.
8. Contact and photo areas must exist, but real information/photos will be added near live launch.

GOAL:
Create a working demo MVP where:
- Customer submits project request.
- Admin sees the submitted request.
- Worker uploads photos through private link.
- Admin sees uploaded photos.
- Admin approves and writes clean description.
- Customer tracking link shows only approved updates.
- UX is simple enough for older users.
- Public pages have less reading and clearer actions.
